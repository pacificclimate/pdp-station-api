Contributing and getting help
=============================

You can help by improving examples, reporting unclear instructions, verifying
reported problems, or contributing corrections. Documentation lives in
``docs/source`` in the
`pdp-station-api repository <https://github.com/pacificclimate/pdp-station-api>`_.
Submit documentation changes as a pull request.

Reporting an issue
------------------

Search the `issue tracker <https://github.com/pacificclimate/pdp-station-api/issues>`_
first, then open an issue with:

* The API base URL and version shown in the documentation.
* A minimal request that demonstrates the problem, including constraints or
  aggregate request fields.
* What you expected and what happened, including HTTP status or error text.
* The approximate request time and your client or tool version.

Remove credentials or other private information before posting a request.
For data support, contact ``pcic.support@uvic.ca``.

Documentation checks
--------------------

The repository's ``docs/README.md`` explains how to build and preview the guide.
Pull requests build the documentation with warnings treated as errors. Check
links, variable names, and examples against the API behaviour when making a
change.
